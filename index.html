このタイピングゲームの特徴・違い・遊び方を見る

本ページは、漢字変換（IME）を含めた日本語入力練習を目的とした社会人向けタイピングゲームの公式ページです。 仕事で必要な「完成文の速さ」を伸ばすことを重視しています。

特徴

  • 漢字変換（IME）対応：変換・確定まで含めた実務寄り入力練習
  • 文章コンテンツ：読みながら続けられる（雑学テーマ）
  • 成長グラフ：完成文ベースCPMの推移を可視化
  • ランキング：日替課題／全国／グループ
  • フリック入力・外付けキーボード：スマホでも練習しやすい

一般的なタイピングゲームとの違い

一般的なタイピングゲームはローマ字入力の速さに寄りがちですが、本サイトは日本語変換（IME）込みで判定します。 「読む → 入力する → 変換する → 正確に仕上げる」をまとめて練習したい方に適しています。

遊び方

  1. まず ユーザー を選択・作成（1台で複数人管理可能）
  2. 必要なら グループ を作成・参加（身内ランキング）
  3. 難易度・文章長・カテゴリ／テーマを選択（迷ったら日替課題）
  4. 文章を読み、IMEで漢字変換しながら入力
  5. 完了後、スコア（完成文ベースCPM）・ランキング・成長グラフを確認

            よくある質問（FAQ）

            IMEとは何ですか？

            IME（Input Method Editor）とは、日本語入力でローマ字をひらがな・漢字・カタカナへ変換する仕組みです。
            → IMEの仕組みを詳しく解説

            CPMとは何ですか？

            CPM（Characters Per Minute）は1分間に入力できた文字数を表します。
            当サイトはIME変換・確定を含む完成文ベースで評価します。
            → 完成文ベースCPMとは？

            漢字変換のあるタイピング練習はできますか？

            はい。本ゲームはIME変換込みで判定します。
            → 漢字変換タイピングとは

            社会人向けのタイピング練習として使えますか？

            はい。ローマ字打鍵ではなく、変換・確定・修正を含めた「文章を完成させる入力」を重視しています。

            グループ対戦（身内ランキング）はできますか？

            はい。グループを作成・参加すると、友人・会社・学校などのメンバーでランキング形式の対戦ができます。 全国ランキングにも同時参加できます。

            成長をグラフで確認できますか？

            はい。スコア（完成文ベースCPM）の推移グラフを自動生成し、日々の成長を視覚的に確認できます。

            スマートフォンのフリック入力でも使えますか？

            はい。スマートフォンのフリック入力でもスコア計測が可能で、ランキングやグループ対戦にも参加できます。 外付けキーボードを接続しての入力にも対応しています。
